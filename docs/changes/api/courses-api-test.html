P1.7 建课接口 · 后端 FastAPI @ 127.0.0.1:8000

先看这个：CORS 决定了页面能不能连上后端

后端 app/main.py 只放行两个来源： http://localhost:5173 和 http://127.0.0.1:5173。 直接双击打开本文件（file://）会被浏览器拦掉，页面上只会看到 Failed to fetch。

推荐做法（二选一，都不用改后端代码）：

# 方式 A：用 5173 起一个静态服务器（这个端口在后端白名单里）
cd docs/changes/api
python -m http.server 5173
# 然后浏览器打开 http://localhost:5173/courses-api-test.html
# 方式 B：把页面丢进 Vite 的 public 目录，让前端 dev server 代发
copy docs/changes/api/courses-api-test.html apps/web/public/
npm --prefix apps/web run dev
# 然后浏览器打开 http://localhost:5173/courses-api-test.html

后端起法：cd apps/api → .venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
