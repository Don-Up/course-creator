# 课程 MISSION

## 课程标识
- 课程名称：从零开始，学会搭建一个酷炫的 Obsidian 个人知识库
- 课程 slug：advanced-learning-of-obsidian
- 版本：1.0

## 受众
课程面向 0 基础或只有少量编程经验、对 AI 全栈开发感兴趣的学习者。默认学习者只掌握简单的编程基础，希望通过本课程完整学习 RAG 和 Obsidian，因此首次出现的术语、概念和复杂机制都要先解释并提供必要铺垫。

## 学习成果
1. 理解 Obsidian 是什么、为什么出现、解决什么问题，以及与 RAG 的异同。
2. 能够解释 Obsidian 在 AI 工程化领域中的作用。
3. 独立完成从基础使用到搭建一个个人的 Obsidian 知识库的渐进实践。
4. 掌握面向 RAG 的 Markdown 数据建模、AST 解析与分块策略。
5. 能够通过插件架构接入云端大模型 API，并理解其工作原理。
6. 具备部署全本地离线 RAG 架构（Ollama + 本地向量数据库）的能力。
7. 熟悉混合检索与重排序技术，解决传统 RAG 召回精度问题。
8. 理解 GraphRAG 原理，并能将 Obsidian 双链与知识图谱融合。
9. 能够通过 MCP 将 Obsidian 知识库暴露为外部工具的上下文服务。
10. 掌握 RAG 效果评估与知识库维护方法，实现 Agentic 工作流闭环。

## 范围
本课程共 9 章，每章有效字符数不低于 10,000 字，内容覆盖以下主题：

### 第 1 章：个人知识库选型与 RAG 演进哲学
知识库工具选型对比：Obsidian (Local-first Markdown)、Notion (Cloud/Block DB)、企业级 RAG 系统 (Dify / RAGFlow)。RAG 架构的演进脉络：Naive RAG → Advanced RAG → GraphRAG → Agentic RAG/MCP。学习目标：理解各选型的适用场景，明确为何 Obsidian 是开发者搭建“个人 AI 第二大脑”的最佳本地轻量级载体。

### 第 2 章：面向 RAG 的 Markdown 数据建模与 AST 解析
高质量向量化数据源搭建：原子化笔记、YAML Frontmatter 元数据设计。Markdown 的分块策略：基于 AST 的递归切分，父子文档策略。学习目标：掌握针对 Markdown 文本的数据清洗与结构化设计，提升召回准度。

### 第 3 章：插件架构拆解与云端 API 快速落地
Obsidian 流行 AI 插件工作原理拆解：Smart Connections 本地索引缓存、Copilot/Smart Composer 的上下文窗口与流式输出。接入云端大模型 API（DeepSeek / OpenAI / Claude），检查本地向量数据结构。学习目标：跑通端到端链路，并从代码逻辑层面理解插件与 Obsidian API 的交互。

### 第 4 章：全本地离线闭环——Ollama + 本地 Vector DB 部署
本地模型选型与算力评估：Embedding 模型（bge-m3、nomic-embed-text），LLM 推理引擎（Ollama / LM Studio 部署 Qwen2.5 或 DeepSeek-R1 蒸馏版）。配置本地服务暴露 OpenAI 兼容接口，实现 100% 离线运行、零数据上云的本地 RAG。学习目标：建立一套不依赖任何外部付费 API 的私有安全 RAG 架构。

### 第 5 章：Advanced RAG 进阶——混合检索与 Re-ranking
纯向量检索的局限，混合检索架构：Sparse Search (BM25) + Dense Search 融合算法 (RRF)。引入重排序模型（bge-reranker）对 Top-K 结果二次打分。学习目标：解决传统 RAG 召回精度差、检索“似是而非”的痛点。

### 第 6 章：突破语义局限——基于 Obsidian 双链的 GraphRAG
向量 RAG 的瓶颈，GraphRAG 原理：实体与关系提取，构建知识图谱。微软 GraphRAG 理念与轻量级实现（LightRAG / Simple Graph Builder 插件）。Obsidian 原生双链作为显式图边，实现多跳推理。学习目标：掌握 GraphRAG 理论与双链结合方式，提升 AI 处理复杂逻辑关联的能力。

### 第 7 章：Obsidian 3D 视觉化——关系图谱与进阶效果
基于社区插件的 3D 关系图谱实现，将平面笔记网络转化为立体、可旋转的动态三维空间。讲解插件安装配置、视觉效果优化、与双链知识的结合，以及利用 3D 图谱辅助知识探索与创意发现。学习目标：掌握 Obsidian 3D 图谱的启用与定制，理解其渲染原理，并将三维视觉化融入个人知识库的探索与展示流程。

### 第 8 章：开发者扩展——基于 MCP 与外部生态联动
MCP 协议介绍，将 Obsidian 知识库作为 MCP Server 暴露给 Cursor、Claude Code 等工具。自动化脚本开发：Python 监听文件变动，配合 LangChain/LlamaIndex 自动更新外部向量数据库。学习目标：让 Obsidian 成为全工作流的上下文提供者。

### 第 9 章：知识库评估、维护与 Agentic 工作流闭环
RAG 效果评估：RAGAS 框架的忠实度、答案相关性、上下文精准度。知识库防衰退与垃圾回收，增量更新中的向量漂移与冗余清理。Agentic 闭环工作流：提出课题 → 检索 → 生成草稿 → 自动创建笔记并写回双链和 Tag。学习目标：实现知识从输入到检索、辅助思考、自动写回的可持续演进闭环。
